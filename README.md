# edge-tts-gui
A simple edge-tts GUI without any dependencies. Just download the executable.

Shortcuts:
- `Ctrl` + `Enter`: Play
- `Ctrl` + `S`: Save

Global shortcuts:
- `F9`: Quick read selected text (or OCR fallback for captured images)
